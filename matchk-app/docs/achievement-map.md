# 업적지도 ① 전체지도 — 색칠형 폴리곤 맵 설명서

`src/screens/AchievementMapScreen.tsx` 담당: 현표
최종 수정: 2026-08-31

## 개요

부산 16개 구·군을 `react-native-svg`의 `<Polygon>`으로 그린 지도. 실제 부산
행정지도(사용자 제공 참고 이미지)를 보고 손으로 뜬 근사 폴리곤이라, 정확한 GIS
좌표는 아니지만 강서구가 서쪽에 크게, 기장군이 북동쪽으로 튀어나오고, 영도구가
남쪽에 좁은 목으로 이어진 섬 형태인 것처럼 **실제 지형의 실루엣과 인접 관계**는
맞춰뒀다.

- 탭하면 바로 그 구 상세(`DistrictLandmarks`, ③페이지)로 이동한다.
- 헤더의 "리스트로 보기"를 누르면 기존 그리드 화면(②
  `AchievementDistrictsScreen`)으로 갈 수 있다 — 지도 대신 목록으로 훑어보고
  싶은 사람을 위한 대안 화면.

## 색상 규칙

두 가지 값이 독립적으로 색을 결정한다.

1. **구별 고유색 (`fill`)** — 구를 한눈에 구분하기 위해 구마다 다른 색을 쓴다.
   HSL 색상환을 16등분해서 배정했다 (`S 58% · L 48%` 고정, `H`만 회전).
2. **도장 비율 (`fillOpacity`)** — 그 구의 고유색을 얼마나 진하게 칠할지를
   도장 수집 비율로 결정한다. 공식:

   ```
   fillOpacity = 0.12 + progress * 0.88
   ```

   - `progress = 0` (도장 0개) → `opacity 0.12` (거의 흰색에 가까운 옅은 틴트)
   - `progress = 1` (그 구 도장 100% 수집) → `opacity 1.00` (완전히 진한 색)
   - 즉 **같은 구라도 도장을 모을수록 점점 진하게 칠해진다** — 색 자체가
     바뀌는 게 아니라 "칠하는 진하기"가 바뀌는 것.

3. **소멸위험 구(동구·서구·영도구)** — 위 두 값과 별개로 항상 금색
   (`colors.stampGold`) 테두리가 덧씌워진다. 고유색·진행률 상태와 무관하게
   항상 표시되어 "이 구는 소멸위험 지역입니다"를 알려준다.

## 라벨 텍스트 색

`progress > 0.5`면 흰색, 아니면 어두운 텍스트(`colors.textPrimary`). 진하게
칠해진 구(칠 자체가 진해서 배경이 어두움) 위에서도 글자가 읽히게 하기 위함.

## 데이터 구조

`LAYOUT` 배열(파일 상단)의 각 항목:

```ts
{
  code: number;       // sigunguCode — 백엔드 District.sigungu_code와 매칭
  nameKo: string;      // 폴백 이름 (백엔드 응답 없을 때만 사용)
  points: string;      // <Polygon points="x,y x,y ...">, viewBox 0 0 680 720
  labelX, labelY: number; // 라벨 텍스트 중심 좌표 (폴리곤 centroid)
  color: string;       // 구별 고유색 (위 팔레트 표)
}
```

`endpoints.progress()` 응답(`/api/stamps/progress`)에서 받은 `districts[]`를
`sigunguCode` 기준으로 `LAYOUT`과 매칭해서 실제 `progress`/`isDeclining`/`name`
값을 채운다. 응답이 아직 없거나 실패하면 `progress=0`으로 렌더링되어 지도
자체는 항상 바로 보인다(로딩 스피너로 안 막음).

## 디자인팀 최종 지도로 교체하는 법

1. `LAYOUT`의 각 `points` 값만 새 폴리곤 좌표로 교체 (viewBox·매칭 로직은
   그대로 재사용 가능)
2. 최종 디자인에 이미 색이 정해져 있으면 `color` 값도 같이 교체
3. `labelX`/`labelY`는 새 폴리곤의 대략적인 중심으로 재조정

## 테스트 계정 (10% 단위 진행률 검증용)

`fillOpacity` 그라데이션이 실제로 잘 보이는지 확인하기 위한 테스트 계정
생성 스크립트: `matchk-api/app/scripts/seed_progress_demo.py`. 자세한 내용은
그 스크립트 상단 주석과 실행 결과 출력 참고. (API 레벨 검증용 — 앱에
계정 전환 UI가 없어서 폰 화면에서 바로 이 계정들로 로그인해볼 수는 없다.)

## 폰 화면에서 바로 보기 — 개발용 색칠 미리보기

위 테스트 계정의 한계(폰에서 직접 못 봄)를 보완하기 위해, 화면 맨 아래에
`__DEV__`(개발 빌드)에서만 보이는 미리보기 칩 11개(0~100%, 10% 단위)를 넣었다.
아무 칩이나 탭하면 **모든 구가 그 퍼센트로 즉시 칠해진 것처럼** 보여준다(실제
도장 데이터는 안 건드림, 화면 표시만 오버라이드). 다시 탭하면 해제되고 실제
데이터로 돌아온다. 프로덕션 빌드에서는 `__DEV__`가 `false`라 이 UI 자체가
렌더되지 않는다.
